# Source Visualizer

## Open the live app

**[Launch Source Visualizer](https://fazelifestyle184-eng.github.io/oxysbabies/)**

> **Heads up:** im still learning how to use python and coding so please bare with me as i work to make this more customizable and just better overall

The app analyzes audio from a local file or a browser tab and displays a colorful,
full-page spectrum visualizer. The small muted YouTube window can be dragged and resized.

## Use it

1. Open the launch link above.
2. Choose an audio file, or click **Capture browser tab audio** and share a browser tab with audio enabled.
3. Adjust glow, bar count, bar height, color speed, and frequency range as desired.
4. Open **Show controls** and use the **Audio**, **Visuals**, and **Video** tabs to keep the customization options organized. The Visuals tab includes a sphere-shaped bar mode and a frequency-map randomizer.

Desktop-app and entire-screen capture are currently disabled. For Spotify, use Spotify in a browser tab, play the music first, click **Capture browser tab audio**, and enable **Share tab audio**.
